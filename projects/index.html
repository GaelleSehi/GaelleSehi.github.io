A selection of projects in mosquito ecology, forecasting, simulation, and spatial access to care.

Ecological modeling of Aedes aegypti abundance

This project examined environmental drivers of Aedes aegypti abundance in the West Valley region of San Bernardino County from 2017 to 2023 using ecological modeling approaches.

Mosquito forecasting (2017–2023)

This project focuses on 2-week-ahead site-level forecasts of mosquito abundance using surveillance, environmental, and spatial predictors. It compares GAM, Random Forest, and spatial Random Forest approaches.

Tick-borne encephalitis (TBE) modeling for Germany

Part of the VBD-MODE consortium, this project builds a multi-model ensemble — combining GAM, INLA, XGBoost, tick phenology, species distribution-derived receptivity indices, and cost-effectiveness analysis — to forecast TBE risk across Germany and support public health decision-making.

SIT simulation / agent-based modeling

This project uses an agent-based model to compare area-wide and targeted sterile insect technique (SIT) release strategies and to explore their operational and cost implications.

Healthcare access (Côte d'Ivoire)

This project evaluates geographic access to care in Côte d'Ivoire using travel-time models built from population, roads, land cover, and elevation data, using OpenStreetMap facility data.
