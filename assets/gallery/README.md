Drop your hike/trip photos in this folder, named photo-01.jpg, photo-02.jpg, etc.
(6 slots are set up in gallery/index.html — add or remove <figure> blocks there to change the count.)

For each photo, also edit the caption text in gallery/index.html:
  <figcaption>Caption goes here</figcaption>

Recommended: compress large phone photos before uploading (aim for under ~500KB each)
so the gallery page loads fast. squoosh.app works well for this.
